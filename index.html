☁️ 서버 연결 안내

이 사이트는 Supabase(무료 데이터베이스)를 서버로 사용합니다. 연결되면 로그인 후 어느 기기에서 수정하든 즉시 모두에게 반영되고, 숨긴 영상은 서버가 직접 막아주기 때문에 일반 방문자는 아예 받아갈 수 없습니다.

  1. supabase.com 에서 무료 가입 후 프로젝트 생성
  2. Project Settings → API 에서 Project URL 과 anon public 키 복사
  3. 그 두 값을 전달하면 사이트에 연결해 드립니다 (테이블·권한·기존 13편 이전까지 자동 처리)

anon 키는 외부에 공개되어도 되는 값입니다. 실제 수정 권한은 로그인한 관리자에게만 열리도록 서버에서 막습니다.
